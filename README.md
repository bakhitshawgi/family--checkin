# Family check-in

One-tap prayer check-in page. Each tap submits a Google Form response, which feeds the family Google Sheet (exact time, on time / late, points).

- `index.html` – the page (static, no build step).
- First open: paste the Google Form pre-filled link once (Yousuf + Fajr selected) to connect the buttons, or set `CONFIG` at the top of the script.

Served with GitHub Pages from the `main` branch root.
